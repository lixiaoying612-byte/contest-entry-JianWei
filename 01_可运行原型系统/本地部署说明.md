# 见微 · 可运行原型系统

适用：Windows 10/11、x64。无需账号登录，默认演示工作区。

1. **完整解压 `见微_Windows运行包.zip`。**
2. 打开解压后的 `见微` 文件夹，双击 **`启动见微.cmd`**。
3. 浏览器打开见微；未自动打开时访问 `http://127.0.0.1:8780/?mode=real&run=training-showcase`。
4. 保留启动窗口。关闭窗口或按 `Ctrl+C` 停止，下次启动保留数据。

运行包自带 Python 3.12.14、三个直接依赖、完整源码、必要规则与 **160 条保存事件**。无需另装 Python、Node.js、数据库或模型权重。

四页可浏览原文、事项进展、评分依据、影响判断和预警。新闻导入后点击分析按钮才会调用 DeepSeek，每次主动分析最多两次发送。已预配演示访问配置，分析新新闻需要网络及可用供应商额度；浏览保存案例不需要联网。

命令提示符中执行 `启动见微.cmd --offline` 可离线启动，`启动见微.cmd --port 8781` 可换端口。新材料与操作保存在运行包内 `artifacts/eng063/local/`；首次启动复制示例库，后续不覆盖工作库。

完整环境、配置、测试、备份和常见问题见仓库根 [README](../README.md)。代码阅读与二次部署使用 [02_源代码](../02_源代码/)
