# 报告统计复算

`report-metrics.json` 保留固定 30 篇的对象、方向、事件类别参考标签和事前保存的对话识别标签，以及程序实验每篇耗时、发送次数和档案数。记录从原始冻结结果提取，不含新闻正文、完整模型请求、费用账本或凭据，不作为产品检索材料。

在 Windows 运行包目录执行：

```bat
python\python.exe -X utf8 -I scripts\reproduce_report_metrics.py
```

在源码目录使用自己的 Python 执行：

```powershell
python -X utf8 scripts/reproduce_report_metrics.py
```

复算只使用 Python 标准库，无需联网。结果为：公司对象 21/23、行业对象 6/7、总体对象 27/30、对象及方向 25/30、对象及类别 24/30、三项联合 23/30。后两类指标要求同一对象的相应字段一致；同篇所有参考标注均命中才计该篇通过。

这些识别比例属于**对话识别组**，不能作为程序自动识别准确率。另行复算的程序运行记录为 28/30 篇生成可读档案、58 次模型发送、平均 64.50 秒、中位数 60.44 秒、最长 89.27 秒；这些是历史实验的计时。

本脚本重新执行标签比较与汇总计算，验证报告数字。它不重新生成预测、不运行历史收费模型请求，也不重做未随包分发的全量赛事语料实验。随包新新闻处理回放另见 `tests/test_news_pipeline.py`；真实新新闻可通过产品界面主动联网分析。
